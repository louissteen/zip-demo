# App Studio

App Studio is the extensibility layer of Zip. It lets an administrator model something Zip does not model out of the box, attach automation to it, and publish it to colleagues as an app they can use.

The objects you create behave like the ones Zip ships. They carry permissions, appear in views and dashboards, run workflows, and write to the audit log. That is the point: an extension built here inherits the controls rather than sitting beside them.

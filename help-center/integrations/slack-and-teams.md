# Slack and Microsoft Teams

The chat integrations put approvals where your approvers already are. Most organizations see approval times drop noticeably after enabling them.

## What you can do from chat

* Receive a notification when something needs your approval
* Approve or reject directly from the message
* Ask a question, which posts back to the request timeline
* Look up the status of a request with a slash command

## Installing

{% stepper %}
{% step %}
## Install the app

A workspace administrator installs the Zip app from the Slack or Teams app directory.
{% endstep %}

{% step %}
## Connect it to your Zip account

In Zip, go to **Settings**, then **Integrations**, and authorize the connection.
{% endstep %}

{% step %}
## Let users link their accounts

Each user links their chat identity to their Zip user the first time they interact with a notification.
{% endstep %}
{% endstepper %}

## Choosing what gets sent

Notification preferences are per user under **Settings**, then **Notifications**. You can route approval requests to chat, email, or both, and set a daily digest instead of individual messages.

{% hint style="info" %}
Approvals taken in chat are recorded on the request timeline with the same audit detail as approvals taken in Zip.
{% endhint %}

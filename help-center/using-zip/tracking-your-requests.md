# Tracking your requests

The **My requests** page lists everything you have submitted, with its current status and current approver.

## What each status means

| Status | Meaning | What you should do |
| ------ | ------- | ------------------ |
| Draft | Saved but not submitted | Finish and submit it |
| Pending approval | With one or more approvers | Wait, or nudge if it is stalled |
| Information needed | An approver has a question | Answer on the request |
| Approved | Cleared all approvals | Nothing, the PO is being created |
| Rejected | Declined by an approver | Read the reason, revise and resubmit |
| Cancelled | Withdrawn | Nothing |

## Reading the timeline

Every request has a timeline showing each approval step, who acted, when, and any comments. The timeline is the record of what happened, so put questions and answers there rather than in email.

## Nudging a stalled request

Select **Nudge** on the request to remind the current approver. The nudge is recorded on the timeline and sent by email, and in Slack or Teams where that integration is enabled.

{% hint style="info" %}
If an approver is out of office and has not set a delegate, ask a Zip administrator to reassign the step rather than waiting for their return.
{% endhint %}

## After approval

Once a request is approved, Zip creates a purchase order and, where the ERP integration is enabled, syncs it to your accounting system. See [Purchase order details](purchase-order-details.md) for what happens next.

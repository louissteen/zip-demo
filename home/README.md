# Zip documentation

Zip orchestrates procurement from the first request to the final payment. A requester raises an intake request, Zip routes it to finance, legal, IT security, and procurement, turns the approved request into a purchase order, matches the vendor invoice against it, and takes the bill through to payout.

These docs cover the whole platform: the products your teams work in every day, the vendor-facing portal, the governance layer behind Zip's AI features, and the API.

# Spend insights

Spend insights reports on the data Zip creates as a byproduct of running the process. Because every request, approval, purchase order, and bill is a structured record, you can answer questions about spend and about the process itself without exporting anything into a spreadsheet first.

Two kinds of question are covered here. Spend questions: who is buying what, from which vendors, against which budgets. Process questions: how long approvals take, where requests wait, and which steps are the constraint. The second kind is what most procurement teams are actually asked about.

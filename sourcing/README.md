# Sourcing

Sourcing is where you put a purchase out to competition before you commit to it. You build an event, invite suppliers, collect structured responses, compare them side by side, and award to the supplier that scores best against criteria you set in advance.

Sourcing is connected to the rest of Zip rather than sitting beside it. An intake request can trigger a sourcing event when the amount or category calls for competition, the awarded supplier flows into onboarding if it is new, and the negotiated price becomes the baseline that savings are measured against.

# Budgets

Budgets is an add-on that puts the budget position in front of the person spending the money, at the moment they ask for it. A requester sees what is left before they submit, an approver sees the impact before they approve, and finance sees variance without exporting anything.

Budgets attach to the same dimensions the rest of Zip uses: subsidiary, department, category, and GL code. Once mapped, every purchase request consumes against the budget its line items code to, and the consumed amount follows the record through the purchase order to the bill.

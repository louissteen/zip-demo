# Intake management

Intake is where a purchase starts. An employee who needs something opens Zip, answers a set of questions, and submits. Everything that follows, the approvals, the contract review, the purchase order, is driven by what that form collected.

Good intake asks the fewest questions that still produce a routable request. This space covers how to build forms, how to use conditional logic so requesters only see what applies to them, how categories organize the catalog of things people can ask for, and how submitted requests are routed. For what happens after routing, see the [Workflow engine](https://app.gitbook.com/s/cCva0sBd9z7KRG56Fq0I/).
